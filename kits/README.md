# Kits de regalo (bundles nativos de Shopify)

Creados el 10 nov 2026 con `productBundleCreate`. Cada kit es un producto propio y Shopify
descuenta el inventario de cada producto que incluye. El stock del kit se calcula solo.
Todos están en la colección **Regalos listos** (`/collections/regalos-listos`), con el tipo de producto
`Kit de Regalo` y la etiqueta `kit-regalo`.
